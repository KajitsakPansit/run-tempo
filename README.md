# Run Tempo

เว็บแอปเมโทรนอมสำหรับวิ่ง ปรับเพซและ BPM ได้ ใช้ได้บนคอมพิวเตอร์และ Chrome บนมือถือ

## วิธีใช้

1. ตั้งเพซเป็นนาทีต่อกิโลเมตร เช่น `10.00` คือ 10 นาที/กม.
2. ใช้ลูกศรปรับทีละ `0.01` หรือรูดแถบเพื่อเปลี่ยนเพซ
3. เลือก BPM แนะนำ หรือปรับ BPM เองด้วยปุ่ม `−` และ `＋`
4. เลือกเสียงติ๊กและปรับความดัง
5. แตะ **เริ่มเมโทรนอม** เพื่อเริ่มเสียง และแตะอีกครั้งเพื่อหยุด
6. เปิด **เทียบว่าเร็ว / BPM** เพื่อดูตารางและเลือกค่า BPM

ค่าตั้งต้นจะบันทึกไว้ในอุปกรณ์เครื่องนั้น และไม่ซิงก์ไปยังโทรศัพท์เครื่องอื่น

## ใช้ขณะล็อกหน้าจอ

บน Android ให้เปิดแอปใน Chrome แตะเริ่มเสียงก่อน จากนั้นติดตั้ง Run Tempo จากเมนู Chrome ด้วย **เพิ่มลงในหน้าจอหลัก** หรือ **ติดตั้งแอป** การแสดงปุ่มควบคุมบนหน้าจอล็อกและการเล่นต่อขึ้นกับ Chrome รุ่นนั้นและการจัดการแบตเตอรี่ของโทรศัพท์

## เปิดในเครื่องเพื่อพัฒนา

```sh
npm install
npm run dev
```

## เผยแพร่ GitHub Pages

Workflow ใน `.github/workflows/deploy.yml` จะ build และเผยแพร่เมื่อมีการ push ไปที่ `main` ระบบปรับ base path ตามชื่อ repository ให้อัตโนมัติ หลัง workflow สำเร็จ เว็บจะอยู่ที่ `https://<บัญชี>.github.io/<ชื่อ-repository>/`
